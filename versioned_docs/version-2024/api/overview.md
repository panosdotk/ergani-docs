# API / Διαλειτουργικότητα

Οι οδηγοί περιλαμβάνουν Web API (REST) για εργοδότες.

## Περιβάλλοντα

### Δοκιμαστικό

```text
REST API:
https://trialeservices.yeka.gr/WebservicesAPI/Api/

REST API UI:
https://trialeservices.yeka.gr/WebservicesAPIUI/
```

Ο οδηγός 2024 επισημαίνει ότι οι υποβολές στο δοκιμαστικό περιβάλλον φέρουν σήμανση **«ΑΚΥΡΟ»** και δεν αποτελούν εφαρμογή νομοθεσίας.

### Παραγωγικό

```text
REST API:
https://eservices.yeka.gr/WebservicesAPI/Api/

REST API UI:
https://eservices.yeka.gr/WebservicesAPIUI/
```

Οι παραπάνω διευθύνσεις είναι όπως αναφέρονται στον οδηγό 01.01.2024.

:::warning
Τα endpoints και οι υπηρεσίες μπορεί να αλλάξουν. Πριν από production integration απαιτείται έλεγχος της νεότερης επίσημης τεχνικής τεκμηρίωσης.
:::
