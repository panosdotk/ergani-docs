# ΕΡΓΑΝΗ II — Επισκόπηση

Ο οδηγός 20.10.2022 περιγράφει τη μετάβαση της οργάνωσης του χρόνου εργασίας σε ψηφιακή, δομημένη μορφή.

## Τι παρακολουθεί

Η νέα διαδικασία παρακολουθεί σε ενιαία μορφή:

- προγραμματισμό ωραρίου,
- δηλωθείσες υπερωρίες,
- προγραμματισμό αδειών,
- τρέχουσα κατάσταση Ψηφιακής Οργάνωσης Χρόνου Εργασίας.

## Απογραφική διαδικασία 2022

Ο οδηγός αναφέρει απογραφική διαδικασία από **01/11/2022 έως 30/11/2022** για το ωράριο απασχόλησης.

Η διαδικασία αφορούσε τη μετάβαση από μη επεξεργάσιμη αποτύπωση του ωραρίου σε ψηφιακή μορφή μέσω των νέων δηλώσεων Οργάνωσης Χρόνου Εργασίας.

## Βασικές διαδικασίες

| Διαδικασία | Περιγραφή |
|---|---|
| Σταθερό Εβδομαδιαίο | Ωράριο για εβδομάδα αναφοράς |
| Μεταβαλλόμενο / Τροποποιούμενο | Ωράριο ανά ημέρα, βάρδιες και μεταβολές |
| Ατομικός | Τροποποίηση για έναν εργαζόμενο και συγκεκριμένη ημερομηνία |
| Άδειες | Προγραμματισμός/δήλωση άδειας |
| Υπερωρίες | Διαδικασία υπερωριών |
| Τρέχουσα Κατάσταση | Προβολή της ψηφιακής οργάνωσης |
