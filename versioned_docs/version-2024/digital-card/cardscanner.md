# Ergani CardScanner

Το CardScanner είναι εφαρμογή για φορητές συσκευές που διαβάζει την Κάρτα Εργασίας σε μορφή QR Code κατά την προσέλευση / αποχώρηση.

## Ροή

```text
QR Code
   ↓
CardScanner
   ↓
Γεγονός έναρξης / λήξης
   ↓
ΠΣ Εργάνη
```

## Εκτός σύνδεσης

Ο οδηγός περιγράφει κατάσταση «Εκτός σύνδεσης» όταν η συσκευή δεν έχει πρόσβαση στο Internet ή δεν μπορεί να συνδεθεί στο ΠΣ Εργάνη.

Η εφαρμογή μπορεί να κρατήσει τα γεγονότα προσωρινά και να τα προωθήσει αργότερα.

## Συσκευές της έκδοσης 2024

Ο οδηγός αναφέρει:

- Android OS 7+
- iOS 11+
- κάμερα
- σύνδεση Wi-Fi ή/και 4G

:::warning
Οι απαιτήσεις λειτουργικού συστήματος είναι έκδοσης-εξαρτώμενες. Η συγκεκριμένη πληροφορία προέρχεται από τον οδηγό 01.01.2024 και δεν πρέπει να θεωρείται σημερινή απαίτηση χωρίς νεότερη επίσημη επιβεβαίωση.
:::
