# Έναρξη / Λήξη Κάρτας

Κάθε γεγονός αφορά έναρξη ή λήξη εργασίας.

## Βασικά στοιχεία γεγονότος

Ο οδηγός περιγράφει πεδία όπως:

| Πεδίο | Σκοπός |
|---|---|
| ΑΦΜ εργαζομένου | Ταυτοποίηση εργαζομένου |
| Τύπος | Έναρξη / λήξη |
| Ημερομηνία αναφοράς | Ημερομηνία της δήλωσης |
| Ημερομηνία/ώρα γεγονότος | Πραγματικός χρόνος |
| Αιτιολογία | Χρησιμοποιείται όταν απαιτείται εκπρόθεσμη υποβολή |
| Κατάσταση | Σε αναμονή / Επιτυχής / Σφάλμα / Εκπρόθεσμη |

## Έλεγχοι

Στον οδηγό αναφέρονται έλεγχοι για:

- ένταξη εργαζομένου,
- ενεργοποίηση Κάρτας,
- ημερομηνία αναφοράς,
- χρόνο υποβολής,
- ειδικές περιπτώσεις αποχώρησης μετά τα μεσάνυχτα.

:::warning Πηγή / ισχύς
Τα πεδία και οι έλεγχοι σε αυτή τη σελίδα αποτυπώνουν τον οδηγό 01.01.2024. Ο οδηγός εφαρμογής 20.02.2026 είναι νεότερος και πρέπει να ελέγχεται μαζί με τις τρέχουσες οδηγίες του συστήματος.
:::
