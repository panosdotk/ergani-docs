# Καταστάσεις δήλωσης Κάρτας

Ο οδηγός 01.01.2024 αναφέρει ότι η «Κατάσταση Υποβολής» μπορεί να έχει:

- **Σε αναμονή**
- **Επιτυχής**
- **Σφάλμα**
- **Εκπρόθεσμη**

Για κατάσταση «Σφάλμα» ή «Εκπρόθεσμη» εμφανίζεται επίσης μήνυμα από την πιο πρόσφατη προσπάθεια υποβολής.

<div className="source-note">
Πηγή: οδηγός 01.01.2024, ενότητα για την κατάσταση υποβολής δηλώσεων Κάρτας.
</div>
