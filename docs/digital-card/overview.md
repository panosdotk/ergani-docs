# Ψηφιακή Κάρτα Εργασίας

Ο μηχανισμός της Κάρτας Εργασίας χρησιμοποιεί τη διαδικασία:

> **Δήλωση έναρξης / λήξης Κάρτας Εργασίας**

για την καταγραφή πραγματικού χρόνου εργασίας.

## Τρόποι υποβολής

Ο οδηγός 01.01.2024 περιγράφει:

- φόρμα,
- XML,
- Web API,
- Ergani CardScanner.

Οι επιχειρήσεις που διαθέτουν σύστημα ωρομέτρησης μπορούν να διασυνδεθούν μέσω Web API, ενώ το CardScanner χρησιμοποιεί QR Code.

## Χρονικό περιθώριο

Ο οδηγός αναφέρει μέγιστη καθυστέρηση γεγονότος **15' ± 1'** για έναρξη/λήξη, ανεξάρτητα από τον τρόπο υποβολής.
