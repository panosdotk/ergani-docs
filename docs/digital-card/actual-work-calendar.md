# Ημερολόγιο Πραγματικής Απασχόλησης

Ο ενιαίος οδηγός 01.01.2024 περιλαμβάνει ξεχωριστή λειτουργία **Ημερολογίου Πραγματικής Απασχόλησης**.

Η λειτουργία διαχωρίζει την προγραμματισμένη οργάνωση χρόνου από τα γεγονότα που καταγράφονται μέσω της Κάρτας.

## Σχετικές λειτουργίες

- γεγονότα έναρξης / λήξης,
- αναλυτικές δηλώσεις για ημερομηνία και παράρτημα,
- προβολή πραγματικής απασχόλησης.

<div className="source-note">
Πηγή: οδηγός 01.01.2024, ενότητες 4.3.2–4.3.3.
</div>

:::warning Πηγή / ισχύς
Η περιγραφή βασίζεται στον οδηγό 01.01.2024. Για τρέχουσα συμπεριφορά του συστήματος, διασταυρώστε με νεότερες επίσημες ανακοινώσεις.
:::
