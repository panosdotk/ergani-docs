# Πίνακας βασικών κανόνων

| Θέμα | Τι αναφέρει η πηγή | Έκδοση |
|---|---|---|
| Απογραφή ωραρίου | 01/11/2022–30/11/2022 | 20.10.2022 |
| Ευέλικτη προσέλευση | Έως 120' | 01.01.2024 |
| Κάρτα start/end | Μέγιστη καθυστέρηση 15' ± 1' | 01.01.2024 |
| Εκπρόθεσμη Κάρτα | Απαιτείται αιτιολογία | 01.01.2024 |
| CardScanner | QR Code | 01.01.2024 |
| Card status | Σε αναμονή / Επιτυχής / Σφάλμα / Εκπρόθεσμη | 01.01.2024 |
| Trial submissions | Σήμανση «ΑΚΥΡΟ» | 01.01.2024 |

:::warning
Αυτός είναι πίνακας περιεχομένου των συγκεκριμένων οδηγών, όχι πίνακας ισχύουσας νομοθεσίας για το 2026.
:::
