# Μεταβατικές υποχρεώσεις κατά την έναρξη του ΕΡΓΑΝΗ II

Ο Οδηγός Εφαρμογής 20.02.2026 περιγράφει συγκεκριμένες μεταβατικές υποχρεώσεις για να αποτυπωθεί σωστά η τρέχουσα κατάσταση προσωπικού κατά την έναρξη παραγωγικής λειτουργίας.

## Περιπτώσεις που επισημαίνει ο οδηγός

1. Εργαζόμενοι που εξακολουθούν να εμφανίζονται στην τρέχουσα κατάσταση ενώ η σχέση εργασίας έχει λήξει (ενδεικτικά λόγω θανάτου, λήξης δανεισμού/τοποθέτησης ή μεταβίβασης).
2. Ενεργές σχέσεις γνήσιου δανεισμού ή προσωρινής απασχόλησης που πρέπει να αποτυπωθούν με τη νέα δήλωση έναρξης δανεισμού/τοποθέτησης.
3. Ενεργές ατομικές ή συλλογικές συμφωνίες διευθέτησης χρόνου εργασίας που πρέπει να δηλωθούν στη νέα ροή μεταβολής.

## Προθεσμία που αναφέρεται στην έκδοση Φεβρουαρίου 2026

Για τις παραπάνω συγκεκριμένες περιπτώσεις, ο οδηγός αναφέρει προθεσμία **έως 16/04/2026**. Η ημερομηνία αυτή έχει παρέλθει. Η σελίδα καταγράφει την ιστορική οδηγία της συγκεκριμένης έκδοσης και **δεν επιβεβαιώνει** αν δόθηκε μεταγενέστερη παράταση ή νεότερη οδηγία.

Πριν ενεργήσετε σήμερα για εκκρεμή μεταβατική περίπτωση, ελέγξτε τις νεότερες επίσημες ανακοινώσεις ή επικοινωνήστε με την αρμόδια υπηρεσία.
