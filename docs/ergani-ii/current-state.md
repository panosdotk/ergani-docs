# Τρέχουσα Κατάσταση Ψηφιακής Οργάνωσης

Η «Τρέχουσα Κατάσταση Ψηφιακής Οργάνωσης Χρόνου Εργασίας» αποτελεί την ψηφιακή απεικόνιση του προγραμματισμένου χρόνου εργασίας ανά ημέρα.

## Τι εξυπηρετεί

- προβολή της τρέχουσας οργάνωσης,
- έλεγχο του προγραμματισμένου ωραρίου,
- συσχέτιση με εργαζόμενο και παράρτημα,
- χρήση ως βάση για τις επόμενες διαδικασίες.

## Μετά από πρόσληψη

Ο οδηγός 01.01.2024 αναφέρει ότι ο εργαζόμενος εμφανίζεται στην Τρέχουσα Κατάσταση στην ημερομηνία πρόσληψης και ώρα έναρξης. Για τις επόμενες ημέρες πρέπει να υποβληθεί Ψηφιακή Οργάνωση Χρόνου Εργασίας.


## Διάκριση από τη Μηνιαία Εργασιακή Κατάσταση

Η «Τρέχουσα Κατάσταση Ψηφιακής Οργάνωσης Χρόνου Εργασίας» είναι διαφορετική έννοια από τη «Μηνιαία Εργασιακή Κατάσταση» του οδηγού 20.02.2026. Η πρώτη αφορά την εικόνα της οργάνωσης χρόνου· η δεύτερη είναι μηνιαία συγκεντρωτική εξαγωγή στοιχείων εργασιακής σχέσης, οργάνωσης χρόνου και κάρτας. Βλ. [Μηνιαία Εργασιακή Κατάσταση](./monthly-employment-status).

:::info Πηγή
Η περιγραφή της Τρέχουσας Κατάστασης βασίζεται κυρίως στον οδηγό 01.01.2024· η νέα ενότητα Μηνιαίας Εργασιακής Κατάστασης βασίζεται στον οδηγό 20.02.2026.
:::
