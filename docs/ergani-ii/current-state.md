# Τρέχουσα Κατάσταση Ψηφιακής Οργάνωσης

Η «Τρέχουσα Κατάσταση Ψηφιακής Οργάνωσης Χρόνου Εργασίας» αποτελεί την ψηφιακή απεικόνιση του προγραμματισμένου χρόνου εργασίας ανά ημέρα.

## Τι εξυπηρετεί

- προβολή της τρέχουσας οργάνωσης,
- έλεγχο του προγραμματισμένου ωραρίου,
- συσχέτιση με εργαζόμενο και παράρτημα,
- χρήση ως βάση για τις επόμενες διαδικασίες.

## Μετά από πρόσληψη

Ο οδηγός 01.01.2024 αναφέρει ότι ο εργαζόμενος εμφανίζεται στην Τρέχουσα Κατάσταση στην ημερομηνία πρόσληψης και ώρα έναρξης. Για τις επόμενες ημέρες πρέπει να υποβληθεί Ψηφιακή Οργάνωση Χρόνου Εργασίας.
