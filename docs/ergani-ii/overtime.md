# Υπερωρίες

Ο οδηγός 20.10.2022 αναφέρει ότι οι δηλωθείσες υπερωρίες παρακολουθούνται στο πλαίσιο της Ψηφιακής Οργάνωσης Χρόνου Εργασίας και ότι για τις υπερωρίες παραμένει η ισχύουσα διαδικασία.

Η τεκμηρίωση του Ε8 μπορεί να αποτελέσει ξεχωριστή σελίδα όταν μεταφερθεί πλήρως το σχετικό υλικό.
