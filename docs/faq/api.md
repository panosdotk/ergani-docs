# FAQ API

## Πρέπει να γίνεται Authentication πριν από κάθε request;

Ο οδηγός περιγράφει authentication που παράγει access/refresh tokens και χρήση του access token στις επόμενες κλήσεις. Το access token ανανεώνεται μέσω RefreshAuthentication.

## Ποιος είναι ο κωδικός της Κάρτας;

Στον οδηγό εμφανίζεται ο κωδικός υποβολής:

```text
WRKCardSE
```

για δήλωση έναρξης/λήξης εργασίας.

## Ποιο περιβάλλον πρέπει να χρησιμοποιώ για tests;

Το trial περιβάλλον. Οι υποβολές εκεί φέρουν σήμανση «ΑΚΥΡΟ» σύμφωνα με τον οδηγό 01.01.2024.
