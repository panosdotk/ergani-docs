# FAQ API

## Ποιο είναι το trial API για τη νέα έκδοση;

- REST API: [https://trialv2eservices.yeka.gr/WebservicesAPI/Api/](https://trialv2eservices.yeka.gr/WebservicesAPI/Api/)
- REST API UI: [https://trialv2eservices.yeka.gr/WebservicesAPIUI/](https://trialv2eservices.yeka.gr/WebservicesAPIUI/)

Οι διευθύνσεις αναφέρονται στον Συνοπτικό Οδηγό 12.02.2026.

## Υπάρχει κοινό trial username/password;

Οι οδηγοί δεν παρέχουν κοινόχρηστα στοιχεία σύνδεσης. Περιγράφουν είσοδο με διαπιστευτήρια e-ΕΦΚΑ (ΑΜΕ), ΑΜΟΕ για οικοδομοτεχνικά έργα, χρήστες «ΕΡΓΑΝΗ» για παραρτήματα ή, όπου προβλέπεται, Taxisnet/ΓΓΠΣΔΔ. Χρησιμοποίησε εξουσιοδοτημένα στοιχεία για το συγκεκριμένο περιβάλλον.

## Οι δοκιμαστικές υποβολές είναι πραγματικές;

Όχι. Ο Συνοπτικός Οδηγός 12.02.2026 αναφέρει ότι οι δηλώσεις στο trial φέρουν τη σήμανση «ΑΚΥΡΟ» και δεν αποτελούν εφαρμογή νομοθεσίας.

## Ισχύει ακόμη ο κωδικός `WRKCardSE`;

Ο κωδικός εμφανίζεται στον οδηγό 01.01.2024 για υποβολή δήλωσης έναρξης/λήξης Κάρτας. Οι οδηγοί 2026 παραπέμπουν σε συνοδευτικά JSON examples και στο v2 API UI· επιβεβαίωσε τον τρέχοντα κωδικό πριν από ανάπτυξη.

:::danger
Μην αποθηκεύεις usernames, passwords, access tokens ή refresh tokens μέσα στο δημόσιο repository ή στο documentation site.
:::
