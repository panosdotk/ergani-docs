# Ιστορικό αλλαγών

## v0.2 — Structured Knowledge Base

- Αναδιοργάνωση των docs σε λειτουργικές ενότητες.
- Προσθήκη API reference.
- Προσθήκη XML section.
- Προσθήκη CardScanner.
- Προσθήκη πραγματικού χρόνου / ημερολογίου.
- Προσθήκη statuses.
- Προσθήκη glossary.
- Προσθήκη rules matrix.
- Προετοιμασία για search και AI Q&A.

## 2022 → 2024

Ο οδηγός 2022 επικεντρώνεται στη μετάβαση της Ψηφιακής Οργάνωσης Χρόνου.

Ο οδηγός 2024 ενοποιεί την Οργάνωση Χρόνου και την Ψηφιακή Κάρτα και περιλαμβάνει αναλυτικότερα:

- γεγονότα start/end,
- εκπρόθεσμες υποβολές,
- Ημερολόγιο Πραγματικής Απασχόλησης,
- CardScanner,
- API examples,
- FAQ.
