# ΕΡΓΑΝΗ Documentation

Online knowledge base για **ΕΡΓΑΝΗ II**, **ψηφιακές δηλώσεις εργασιακής σχέσης**, **Ψηφιακή Οργάνωση Χρόνου Εργασίας** και **Ψηφιακή Κάρτα Εργασίας**.

## Πηγές που καλύπτει η έκδοση 2026

- **Πληροφοριακό Σύστημα Εργάνη ΙΙ — Συνοπτικός Οδηγός Εκπλήρωσης Υποχρεώσεων**, έκδοση 12.02.2026 (το εξώφυλλο αναφέρει επίσης «Τελευταία Ενημέρωση: 23/04/2025»· κρατάμε και τις δύο ενδείξεις όπως εμφανίζονται στην πηγή).
- **Πληροφοριακό Σύστημα Εργάνη ΙΙ — Οδηγός Εφαρμογής**, έκδοση 20.02.2026.
- Ιστορικές πηγές: **Ενιαίος Οδηγός Οργάνωσης Χρόνου / Ψηφιακής Κάρτας**, 01.01.2024 και **Εργάνη ΙΙ — Νέες Διαδικασίες**, 20.10.2022.
