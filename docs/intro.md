:::info Τι περιλαμβάνει αυτή η έκδοση
Η έκδοση αυτή οργανώνει σε searchable σελίδες το υλικό των δύο οδηγών που δόθηκαν ως πηγές:

- **Εργάνη ΙΙ – Νέες Διαδικασίες**, έκδοση 20.10.2022
- **Εργάνη ΙΙ – Οργάνωση Χρόνου Εργασίας & Ψηφιακή Κάρτα Εργασίας**, έκδοση 01.01.2024
:::

## Πώς είναι οργανωμένη η γνώση

Κάθε σελίδα προσπαθεί να απαντά σε ένα συγκεκριμένο ερώτημα:

> **Τι είναι → Πότε εφαρμόζεται → Ποια πεδία/βήματα απαιτούνται → Παραδείγματα → Πηγή**

:::warning Σημαντικό
Το site είναι documentation layer πάνω από τους συγκεκριμένους οδηγούς και δεν αποτελεί από μόνο του νομική ερμηνεία. Για κανόνες που μπορεί να έχουν αλλάξει μετά την έκδοση της πηγής, πρέπει να προστεθεί νεότερη επίσημη πηγή.
:::

## Search & AI

Το project είναι προετοιμασμένο για:

1. **Algolia DocSearch** για πλήρες search.
2. **Contextual search ανά έκδοση**.
3. **AI Q&A** που θα απαντά μόνο από indexed documentation και θα επιστρέφει πηγές.
