# XML

Οι οδηγοί υποστηρίζουν υποβολή μέσω αρχείων XML/XSD.

## Αρχές

- Το XML πρέπει να είναι έγκυρο βάσει του αντίστοιχου XSD.
- Μπορεί να περιλαμβάνει μία ή περισσότερες δηλώσεις, ανά διαδικασία.
- Η ίδια διαδικασία μπορεί να διατίθεται και μέσω φόρμας ή API.

## Πού ταιριάζει

```text
Business system
      ↓
XML generator
      ↓
XSD validation
      ↓
ERGANI submission
```

:::tip
Στο επόμενο στάδιο μπορεί να προστεθεί ξεχωριστός φάκελος `schemas/` με τα επίσημα XSD, όταν αυτά δοθούν ως αρχεία.
:::

:::warning Έκδοση πηγής
Η περιγραφή XML βασίζεται στις παλαιότερες πηγές 2022/2024. Για τις τρέχουσες λίστες τιμών, XSD και διαδικασίες του 2026, χρησιμοποιήστε τα επίσημα συνοδευτικά αρχεία του συστήματος.
:::
