# Documents / Υποβολές

## Ανάκτηση PDF

Ο οδηγός περιγράφει route τύπου:

```text
Documents/{code}?protocol={protocol}&submittedDate={yyyymmdd}
```

με `GET`, για ανάκτηση του PDF μιας υποβληθείσας δήλωσης.

Το έγγραφο επιστρέφεται σε μορφή Base64.

## Cancel Document

Ο οδηγός αναφέρει διαδικασία ανάκλησης για συγκεκριμένες διαδικασίες, μεταξύ άλλων:

- Οργάνωση Χρόνου Εργασίας – Άδειες
- Οργάνωση Χρόνου Εργασίας – Άδειες ΟΡΘΗ ΕΠΑΝΑΛΗΨΗ

Η κλήση χρησιμοποιεί στοιχεία όπως κωδικό ενεργής υποβολής, αριθμό πρωτοκόλλου και ημερομηνία υποβολής.
