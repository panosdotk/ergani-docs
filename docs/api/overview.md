# API / Διαλειτουργικότητα

Οι οδηγοί ΕΡΓΑΝΗ II περιγράφουν υπηρεσίες διαλειτουργικότητας REST API. Ο οδηγός εφαρμογής 20.02.2026 παραπέμπει επίσης σε συνοδευτικό συμπιεσμένο φάκελο με παραδείγματα JSON για το REST API. Δεν παραθέτει στο σώμα του πλήρη, επικαιροποιημένο κατάλογο endpoints και payloads· για υλοποίηση χρησιμοποιήστε τα συνοδευτικά αρχεία και το REST API UI.

## Δοκιμαστικό περιβάλλον 2026

- [Πύλη δοκιμών](https://trialv2eservices.yeka.gr/)
- [REST API base](https://trialv2eservices.yeka.gr/WebservicesAPI/Api/)
- [REST API UI](https://trialv2eservices.yeka.gr/WebservicesAPIUI/)

Ο Συνοπτικός Οδηγός αναφέρει ότι οι υποβολές στο δοκιμαστικό περιβάλλον φέρουν τη σήμανση **«ΑΚΥΡΟ»** και δεν αποτελούν εφαρμογή νομοθεσίας.

## Παραγωγικό περιβάλλον 2026

- [Πύλη παραγωγής](https://eservices.yeka.gr/)
- [REST API base](https://eservices.yeka.gr/WebservicesAPI/Api/)
- [REST API UI](https://eservices.yeka.gr/WebservicesAPIUI/)

## Πρόσβαση

Ο Συνοπτικός Οδηγός 12.02.2026 περιγράφει πρόσβαση με κωδικούς e-ΕΦΚΑ (ΑΜΕ), κωδικούς ΑΜΟΕ για οικοδομοτεχνικά έργα, χρήστες «ΕΡΓΑΝΗ» που δημιουργούνται για παραρτήματα και, για περιορισμένες διαδικασίες/κατηγορίες χρηστών, κωδικούς ΓΓΠΣΔΔ/Taxisnet. Δεν δημοσιεύει κοινόχρηστο trial username/password. Χρησιμοποιούνται τα στοιχεία πρόσβασης που αντιστοιχούν στον εργοδότη/χρήστη και στο περιβάλλον.

## Συμβατότητα με τον οδηγό 2024

Οι παλαιότερες σελίδες `api/endpoints`, `api/documents` και `api/card-submission` κρατούν ιστορικές λεπτομέρειες από τον οδηγό 01.01.2024. Μην θεωρήσετε ότι τα παλαιά document codes, routes ή payloads ισχύουν απαραίτητα χωρίς αλλαγή στο περιβάλλον 2026. Ελέγξτε τις τρέχουσες υπηρεσίες στο API UI και τα επίσημα JSON examples.

## Πηγές

- Συνοπτικός Οδηγός 12.02.2026, ενότητες 1–3.
- Οδηγός Εφαρμογής 20.02.2026, ενότητες για περιβάλλοντα και κεφάλαια 11–12.
- Ενιαίος Οδηγός 01.01.2024, κεφάλαιο REST API — ιστορική τεχνική αναφορά.
