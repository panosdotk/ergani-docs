# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Docusaurus 3 (React 19) static documentation site, in Greek (`i18n` locale `el` only), for the Greek ΕΡΓΑΝΗ II labour-ministry system (digital work card, work-time organisation, API/XML). Content is derived from two official PDFs kept in `sources/` (2022 guide and 2024 unified guide). Deployed as static assets via Cloudflare (`wrangler.jsonc` serves `./build`).

There is no test or lint tooling; `npm run build` is the verification step (broken links/markdown links only `warn`, so read the build output).

## Commands

```bash
npm install
npm run start     # dev server
npm run build     # static build into ./build
npm run serve     # serve the built site
npm run clear     # clear Docusaurus cache
```

## Architecture

- **Docs versions**: `docs/` is the `current` version, labelled **2026** and mounted at the docs root (`versions.current.path: ''`, see `docusaurus.config.js`). `versioned_docs/version-2024/` and `version-2022/` (+ `versioned_sidebars/`, `versions.json`) are frozen snapshots marked `unmaintained`. Source archives live in `docs/source-archive/{2024,2026-short,2026-extended}/`. Don't treat 2022/2024 content as current rules — each page should make its source version clear.
- **Curated vs. archive content**: `docs/{ergani-ii,digital-card,api,faq,reference,ai}/` are hand-organised topical pages. `docs/source-archive/{2024,2026-short,2026-extended}/` hold full section-by-section PDF transcriptions, auto-listed in the sidebar. These files set an explicit front-matter `id`, so their URL is `<dir>/<id>`, not the filename — link to them with the `.md` file path (e.g. `./source-archive/2024/01-section-1.md`) to avoid broken-link warnings. The 2022 transcription lives in `versioned_docs/version-2022/source/`.
- **Sidebar**: `sidebars.js` lists curated pages explicitly by doc id (path without `.md`). A new curated page must be added there by hand; archive pages are picked up automatically.
- **Routing**: `docs/intro.md` has `slug: /`; `src/pages/index.js` redirects `/` to `/docs/`. Navbar links like `/docs/changelog` and footer links hardcode doc paths — update them if pages move.
- **RAG/AI metadata** (for the planned AI Q&A, described in `docs/ai/`): `content-index.json` (path/title/language per `docs/` page), `source-manifest.json` (version/source PDF/path/title per archive page) and `rag-schema.json` (chunk schema: title, version, source, section, url, content). These are maintained by hand/script, not generated by the build — update them when adding or renaming docs.

## Notes

- Config sets `markdown.format: 'md'` (the archive transcriptions are not valid MDX). Cloudflare-specific files to preserve when importing a new upstream version: `wrangler.jsonc`, `src/pages/index.js` (redirect to `/docs/`), the `url`/GitHub values in `docusaurus.config.js`, and the local `.gitignore`.
- CI (`.github/workflows/build.yml`) runs `npm ci && npm run build` on pushes to `master` and on PRs.
- Adding a new version snapshot: `npm run docusaurus docs:version <name>`.
